# Skills usadas no projeto LM Comércio e Serviços

Esta pasta registra as instruções das skills utilizadas para planejar, projetar, implementar, revisar e validar este projeto. As cópias são versionadas junto com o site para documentar a origem das decisões e facilitar a reprodução do processo em outro ambiente.

## Inventário

- `webdev`: inicialização, desenvolvimento, diagnóstico, checkpoints, configuração e publicação do site Manus.
- `premium-web-development`: coordenação do fluxo de design e desenvolvimento premium.
- `frontend-design`: direção visual, composição e decisões de interface.
- `ui-ux-pro-max`: recomendações de UI/UX, tipografia, acessibilidade e padrões de interação.
- `design-taste-frontend`: refinamento estético e revisão de qualidade visual.
- `impeccable`: auditoria, polimento, consistência, acessibilidade e revisão de interface.
- `react-bits`: integração de componentes e efeitos React reutilizáveis.
- `aceternity-ui`: integração do componente oficial 3D Card via registry/shadcn.
- `motion`: animações React, springs, Spotlight Cursor, Magnetic Links e respeito a reduced motion.
- `image-processing`: inspeção e preparação determinística de imagens fornecidas para o site.

## Observação

Estas cópias documentam as skills dentro do repositório. O registro global das skills no Manus continua sendo feito pelo ambiente Manus; versionar os arquivos no GitHub não altera automaticamente a biblioteca global de skills.
